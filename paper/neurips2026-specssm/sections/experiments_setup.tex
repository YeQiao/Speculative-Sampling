\paragraph{Models.}

\paragraph{Tiny guided Mamba is all you need.}
A core claim of this work is that a \emph{tiny} SSM drafter, when guided by verifier hidden states, is sufficient for effective speculative decoding.
The Mamba2-27M backbone contains only 27M learnable parameters (excluding the shared tokenizer embedding).
Despite being $44\times$ smaller than LLaMA-3.2-1B, guided Mamba2-27M achieves 2.33 mean accepted tokens, reaches 69\% of LLaMA-1B's acceptance (3.39), and offers unique systems advantages: constant $O(1)$ memory per step (no KV cache growth), compatibility with CPU-offloaded inference (INT8 draft in 9\,ms), and activation replay for efficient state resynchronization.
These properties make tiny guided SSMs a compelling alternative to transformer drafters, particularly in memory-constrained and latency-sensitive deployments.

\paragraph{Baselines.}
We compare against:
\begin{itemize}
  \item \textbf{Autoregressive (AR)}: Standard greedy decoding with the verifier alone (75.8 tok/s on H100 NVL).
  \item \textbf{Mamba2-27M (pretrained)}: Same drafter with no guidance training (pretrained-only).
  \item \textbf{Mamba2-27M (KD, no guide)}: Knowledge-distilled drafter with guidance weights zeroed out. Tests whether the guided checkpoint's backbone has become dependent on guidance signals.
  \item \textbf{LLaMA-3.2-1B drafter}: Standard transformer-based speculative decoding baseline (1.2B parameters).
  \item \textbf{EAGLE-3 chain}~\citep{li2024eagle3}: Public chain-only self-drafting baseline evaluated with its matched LLaMA-3.1-8B-Instruct verifier. Because the released checkpoint is instruct-tuned, we report it as a reference internal baseline rather than a strictly matched base-verifier comparison.
\end{itemize}

\paragraph{Benchmarks.}
We evaluate on five diverse benchmarks: UltraChat~\citep{ding2023ultrachat} (multi-turn dialogue), HumanEval~\citep{chen2021codex} (code generation), XSum~\citep{narayan2018xsum} (summarization), Alpaca~\citep{taori2023alpaca} (instruction following), and GSM8K~\citep{cobbe2021gsm8k} (math reasoning).
Each benchmark is evaluated with 96 samples using greedy decoding ($T\!=\!0$).

\paragraph{Metrics.}
We report:
(i)~\textbf{Average accepted tokens} ($\bar{n}_a$): mean number of draft tokens accepted per speculation round (out of $K\!=\!8$).
(ii)~\textbf{Committed tokens / block efficiency} ($\bar{n}_c$): mean number of tokens committed per round, defined as $\bar{n}_c = \bar{n}_a + 1$ (except EOS/truncation edge cases).
All main results use \emph{rejection masking}: rejected positions are zeroed in the verifier's attention mask to prevent attending to stale key-value entries (\S\ref{sec:masking_analysis}).
(iii)~\textbf{Throughput} (tok/s): end-to-end tokens generated per second.
(iv)~\textbf{Correctness}: we verify that masked speculative outputs match gold AR via logit divergence (mean absolute diff 0.02 with masking vs.\ 4.10 without).

\paragraph{Hardware.}
GPU experiments run on 2$\times$ NVIDIA H100 NVL (95\,GB each).
CPU experiments run on an Intel Xeon Platinum 8562Y+ (Sapphire Rapids) with AVX-512, AVX-512 VNNI, and AMX support.

\paragraph{Hyperparameters.}
Speculation lookahead $K\!=\!8$, non-compact layout, greedy verification.
Guidance layers: $\ell \in \{5, 16, 29\}$ for LLaMA-8B (early, middle, late), $\ell = \{75\}$ for LLaMA-70B.
Guidance injection: x-branch only (\texttt{steer\_z=False}).
Training: AdamW, learning rate $3{\times}10^{-4}$, cosine schedule, batch size 8, sequence length 512.
