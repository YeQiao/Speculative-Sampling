Speculative decoding accelerates large language model inference by drafting candidate tokens with a fast model and verifying them in parallel with the target model.
However, practical speedups depend critically on the drafter's speed, acceptance rate, and systems overhead.
Existing approaches typically use transformer-based drafters that still carry quadratic attention costs, or resort to self-speculation methods that require target-model modifications.
We present \textbf{SpecSSM}, a speculative decoding framework that uses a \emph{tiny} (65M parameter) Mamba2-based state space model as the drafter, guided by hidden-state signals extracted from the transformer verifier.
Our approach injects verifier representations into Mamba2's state-update branch via learned linear projections, enabling the recurrent drafter to approximate the much larger verifier's distribution.
We further propose \emph{activation replay}, an efficient method to resynchronize the SSM's recurrent state after speculative rejection without full re-prefill.
